## 🎯 作業目標與功能對應

### 👤 1. Profile (個人資訊)
- 姓名：**Fanny**
- 個人 Avatar 與在線活躍狀態指示燈
- 科系 / 專長：資訊工程 / 網頁與人工智慧開發
- 簡短自我介紹（支援即時點擊編輯並透過 `localStorage` 本地儲存）

### 🛠 2. Skills (專業技能)
- 🐍 **Python**：核心語言、資料結構與機器學習整合
- 🌐 **Web Development**：HTML5 語意架構、CSS3 毛玻璃主題系統與原生 JavaScript
- 🤖 **AI & Machine Learning**：Prompt Engineering、LLM 智能代理協同開發
- ⚡ **Git & GitHub Workflow**：版本控制、分支管理與 GitHub Pages 自動部署

### 🚀 3. Projects (精選作品與規劃)
- ⏱️ **Fanny's Personal Live Dashboard**：DIC-1 即時個人儀表板（附 GitHub Repo 與 Live Website 連結）
- 💡 **AI 智能學習助手與專注空間**：本學期預計完成之智慧學習與筆記整合專案

### 🕐 4. Live Clock (即時時鐘)
- 精準至毫秒級平滑流暢進度條
- 支援 12H / 24H 即時切換
- 自動偵測系統時區（例如 `UTC+08:00`）與年度週數（Week Number）

### 🎨 5. Personal Design & Bonus (個性化風格)
- 深色 Cosmic 毛玻璃（Glassmorphism）與環境流動光暈動效
- 三套主題即時切換（**Cosmic** 星系、**Aurora** 極光、**Sunset** 日落）
- 動態時間問候（早晨、下午、傍晚、夜晚自動切換 Emoji 與文字）
- 今日時間進度條（Day Progress Tracker）與每日勵志金句小工具（Daily Inspiration）

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS (Custom Properties, Backdrop Filter, Flexbox & Grid)
- **Scripting**: Vanilla JavaScript (ES6+, DOM Manipulation, LocalStorage API)
- **Typography**: Google Fonts (Outfit & JetBrains Mono)
- **Deployment**: GitHub Pages

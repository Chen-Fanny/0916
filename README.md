# Fanny's Personal Dashboard

A modern, glassmorphic personal dashboard featuring a real-time live clock, dynamic time-sensitive greetings, and focus widgets.

## ✨ Features

- ⏱️ **Real-Time Live Clock**: Accurate readout with seconds progress indicator.
- ☀️ **Dynamic Greeting**: Time-aware greetings (Morning, Afternoon, Evening, Night).
- 🎨 **Visual Themes**: Easily cycle between Cosmic, Aurora, and Sunset themes.
- ⌛ **Day Progress Tracker**: Visual progress bar tracking remaining time in the day.
- 💡 **Daily Inspiration**: Motivational quote widget with instant refresh.
- 🚀 **Quick Spaces**: Customizable bookmarks and quick access links.
- ✏️ **Personalization**: Interactive profile name and tagline customization stored locally.

## 🛠️ Tech Stack

- HTML5
- Vanilla CSS (Glassmorphism & CSS Variables)
- Vanilla JavaScript (Zero external runtime dependencies)
- Google Fonts (Outfit, JetBrains Mono)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser.
